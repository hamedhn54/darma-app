# DARMA — اپلیکیشن مالی شخصی

نسخه مستقل اندروید دارما با Flutter و SQLite؛ بدون WebView و بدون وابستگی اجرایی به سایت.

## شروع سریع
1. Flutter SDK نسخه پایدار و Android SDK را نصب کنید.
2. در ریشه مخزن اجرا کنید:
   `bash tool/bootstrap_android.sh`
3. سپس:
   `flutter pub get`
   `flutter run`

اسکریپت، پوشه پلتفرم Android را با Flutter SDK تولید می‌کند و کد برنامه را دست‌نخورده نگه می‌دارد.

## وضعیت نسخه
این Commit، پایه اجرایی محصول است: پوسته Native فارسی و RTL، پنج تم، پایگاه داده SQLite، ساختار دفترکل دوطرفه و ثبت اولیه دریافت/پرداخت. ماژول‌های کامل بودجه، وام، اشخاص، خرید اعتباری و گزارش‌های تفصیلی در مراحل توسعه بعدی روی همین معماری اضافه می‌شوند.

## اصول معماری
- Flutter Native؛ بدون WebView و Capacitor
- SQLite محلی؛ داده‌ها روی دستگاه
- مبالغ در ریال ذخیره می‌شوند
- دفترکل دوطرفه: مجموع بدهکار و بستانکار هر سند باید برابر باشد
- چهار گروه اصلی حساب ثابت هستند: دارایی‌ها، بدهی‌ها، درآمدها و هزینه‌ها
